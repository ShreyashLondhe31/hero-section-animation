# Scroll Driven Motion

A web application demonstrating scroll-driven animation where visual elements move in direct proportion to scroll position.

## Stack

- Next.js (App Router, static export)
- React
- Tailwind CSS
- GSAP and ScrollTrigger

## Running Locally

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build static export:
```bash
npm run build
```

## Verification

Run the verification check script:
```bash
python scripts/check.py
```
